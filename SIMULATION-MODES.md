# madPlanet — режимы симуляции

Зафиксировано при работе над 0.5.52. Это отдельная UI/architecture задача и не должна смешиваться с конкретным погодным milestone.

## Реализм

Режим по умолчанию.

- BASE/GEO параметры задаются пользователем напрямую.
- DERIVED параметры рассчитываются причинной моделью.
- Ручное отклонение DERIVED-параметра допустимо как временное воздействие; после отпускания система возвращается к физическому аттрактору.
- Погода существует только при наличии физических причин: фронты, циклоны, конвекция, молнии и осадки не создаются отдельным procedural gate.
- VISUAL параметры не меняют физику.

## Песочница

Режим свободного конструирования мира.

- Любой пользовательский параметр можно удерживать на выбранном значении без автоматического возврата к расчётному target.
- Автоматическая причинная модель может продолжать считать диагностические «естественные» значения, но не должна молча перезаписывать ручной override.
- UI обязан явно различать ручное значение и рассчитанное значение, чтобы пользователь понимал, что мир физически противоречив намеренно.
- Допускаются экстремальные и заведомо нереалистичные комбинации: сверхчастые молнии, несовместимые температура/атмосфера/облачность и т. п.
- Sandbox override не должен возвращать procedural weather в режим Реализм.

## Требование к реализации

Нужен единый `simulationMode = realism | sandbox`, а не набор локальных исключений в отдельных модулях.

Каждый DERIVED owner должен соблюдать общий контракт:

- `realism`: физический target + временное ручное forcing/relaxation;
- `sandbox`: ручное значение является authoritative до явного сброса override;
- diagnostic physical target продолжает быть доступен отдельно.

Для молний 0.5.52 уже подготовлена правильная граница: в Realism существование грозового очага задаёт Weather Core, а визуальные storm/rate/glow не способны создать очаг из ничего. В будущем Sandbox сможет дать явный manual lightning override поверх этого пути, не изменяя Realism.

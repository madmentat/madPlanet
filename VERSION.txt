VERSION 0.5.119
Base: 0.5.118
Changes: Recompose the smartphone portrait interface into a compact right-aligned service cluster and a four-row bottom dock.
  - Android/narrow portrait layout is now handled by one late mobile policy module instead of unrelated legacy exceptions from the shell, runtime settings and Pause modules
  - hamburger moves to the actual safe top-right corner; program settings and Pause sit immediately to its left, with the simulation-speed cluster on the same right-aligned row when width permits
  - on very narrow portrait screens (<=380 CSS px) only the wider speed control drops to a second right-aligned row; the three compact service buttons remain in the first row
  - all sixteen logical rubric slots are presented as an 8x2 bottom grid with adaptive 34..40 px cells, eliminating horizontal tool scrolling in portrait; empty slots retain layout space and appear only as drag targets while rearranging
  - the utility bar becomes two fixed rows below the tool grid: Ring/Stars/Detail/Plates toggles on the third visual row and Seed/Reroll/Random/Screenshot actions on the fourth/bottom row
  - the whole four-row dock respects Android safe-area insets; hiding the rubric slides both tool and utility regions fully off-screen rather than leaving parts exposed
  - parameter panels, runtime settings and the Thermal legend are lifted above the complete bottom dock so controls are never covered by the new grid
  - desktop, landscape-phone and portrait-tablet layout contracts remain unchanged; this policy is scoped to max-width 700 px plus portrait orientation
Regression: mobile-portrait-layout.js loads after pause-ui.js so its CSS is authoritative over all dynamically created controls; a dedicated regression test guards top service ordering, 8x2 rubric geometry, narrow-screen speed fallback and the two utility rows.
Snapshot: 0.5.118 remains the rollback point before the compact Android portrait dock.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

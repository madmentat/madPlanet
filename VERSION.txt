VERSION 0.5.166
Base: 0.5.165 warm random-world orbital search.
Changes: make the warm-orbit correction the FINAL random-world post-process and remove stale Weather Core feedback between probes.
  - 0.5.165 ran the thermal solver before climate-consistency.js was assembled; climate-consistency then performed another water-equilibrium settle and could cool the accepted world back into a snowball.
  - The thermal acceptance module is now assembled after climate-consistency.js, so no later climate/water wrapper can undo its result.
  - Every orbital probe invalidates the previous Weather Core before H2O equilibrium is settled. This prevents waterTemperatureK() from using the previous cold orbit as feedback for the new candidate.
  - Random worlds still target current T_a +14..+24 °C, with +10..+27 °C as the intended guard band.
  - Regression tests enforce both the final assembly order and the stale-core invalidation order.
  - Manual worlds, river physics, terrain and ordinary Weather Core evolution are unchanged.
Regression: a cold post-processed random world must be warmed only after climate-consistency, and each orbit probe must settle water with no stale Weather Core.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

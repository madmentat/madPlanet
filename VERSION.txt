VERSION 0.5.77
Base: 0.5.76
Changes: Residual tectonic display-seam repair + Android touch ownership + deep-freeze surface-water closure.
Tectonics: 0.5.76 removed hard nearest-plate dmin from physical relief, which reduced the thin arcs substantially. The remaining isolated black/white/dotted curves had a second hard identity path: gSeamNear/gSeamConv still selected one plate pair with `seam < gSeamNear`, and those globals feed the volcanic display path after terrain() is also sampled for finite-difference normals. Pair switching could therefore remain visible even when the physical height field was smooth. The display seam is now a continuous weighted field over nearby pairs using a cheap polynomial distance gate; no single-pair seam choice remains. Physical relief equations and the 0.5.75 non-periodic mountain morphology stay unchanged.
Touch: the canvas already declared CSS touch-action:none, but camera PointerEvent handlers did not explicitly cancel native touch/pen movement. Android Chromium could therefore pan/shift the visual viewport together with the fixed tool UI while the user dragged the planet. Camera pointerdown/move/up/cancel now use passive:false and preventDefault for touch/pen, and runtime touchAction/overscrollBehavior are explicitly pinned to none. Panel gesture arbitration remains separate and still wins in window capture while a panel is open.
Cryosphere: bulk sea-ice thickness remains slow and energy-limited, but visible surface concentration is no longer forced to wait for decimetres of thickness. Typical Earth seawater begins freezing near 271.35 K; below that point a temperature-based thin surface skin raises the minimum sea-ice concentration, reaching effectively complete surface closure by 258.15 K (-15 C). This does not create metres of ice mass: liquid ocean can remain below the insulating cover while the existing thickness model continues to grow slowly. At -46 C or -160 C an exposed Earth-like lake/sea surface can therefore no longer remain visibly liquid merely because bulk thickness has not caught up yet. Procedural inland lakes already use local-temperature phase rendering and remain shore-first near freezing.
Regression: touch-ux test now requires explicit non-passive canvas ownership; cryosphere test requires partial surface closure at mild supercooling and >99.9% closure at -46/-160 C while bulk thickness stays thin; tectonic-cell-seams test forbids hard single-pair gSeamNear selection in addition to the prior dmin/cos guards.
Performance: no Weather Core resolution increase, no new texture units and no new per-frame CPU simulation. Deep-freeze skin is one cheap loop inside the existing cryosphere refresh tick. Tectonic display smoothing reuses the existing plate-pair loop and adds only polynomial weighting/accumulation, not another noise field or exp. Touch changes execute only during pointer interaction.
Validation: confirm visible stamp v0.5.77. Revisit a close tectonic world with Plates OFF and compare with the circled 0.5.76 artifact; isolated ruler-smooth black/dotted arcs should be further reduced. On Android, dragging the canvas must rotate only the planet/star and never move the page/toolbars sideways. For a fresh world at -46 C and especially -160 C, exposed ocean/bay surface should be visually ice-covered after the Weather Core state is available; any remaining dark liquid patch should then be investigated as a sub-grid coastline/inland-water mapping issue rather than slow bulk ice growth.
Retained: 0.5.76 smooth dRef relief weights, 0.5.75 solid polar ice and non-periodic fold morphology, 0.5.74 cubemap seam-aware cryosphere reconstruction, 0.5.73 slow persistent glacier formation, 0.5.72 atmospheric diagnostic toggles, 0.5.71 shore-first water freezing, 0.5.69 cold-stress biomes and temperature diagnostics.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

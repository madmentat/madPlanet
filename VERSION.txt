VERSION 0.5.120
Base: 0.5.119
Changes: Convert user-facing temperature measurements to Celsius and make Thermal Imager resolve active volcanic/lava heat correctly.
  - all currently exposed Planet/Weather temperature readouts are normalized to °C at the UI layer while the physical climate/weather solvers continue using kelvin internally
  - global climate diagnostics no longer show duplicate K + °C values; Weather Core mean air temperature is shown in °C; ocean land/SST contrast uses °C for the temperature difference
  - Thermal Imager legend is now entirely Celsius and spans the ordinary climate range through active-lava skin temperatures, with labels from about -190 °C to +1200 °C
  - Thermal Imager now decodes the actual piecewise GPU temperature format (80..180 / 180..380 / 380..1000 K) instead of incorrectly treating the channel as a linear 180..380 K field
  - ordinary climate temperatures retain most palette precision; extreme hot/cold tails remain visible without flattening the useful terrestrial range
  - active volcanic vents add a sub-grid thermal skin term using the same deterministic arc/hotspot/vent mask as the visible volcano renderer, so hot signatures spatially coincide with volcanic features
  - volcanic heat is intentionally a resolved surface-skin diagnostic rather than a whole Weather Core cell forcing: the synoptic 32..36-cell grid is too coarse to represent a small lava vent without unrealistically heating a huge region
  - lava skin temperature follows the existing lava-activity control over a 600..1200 °C envelope; normal climate physics, world hash and seed are unchanged
Regression: thermal-celsius.test.js guards Celsius-only user labels, packed-temperature decoding, matching visible/thermal volcano geography, lava-temperature range and late Celsius adapter load order in both builders.
Snapshot: 0.5.119 remains the rollback point before Celsius-only UI temperatures and volcanic thermography.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

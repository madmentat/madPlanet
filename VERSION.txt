VERSION 0.5.130
Base: 0.5.129
Changes: Restore physically generated temperate and mid-latitude cloud cover by coupling resolved ascent to condensation instead of requiring whole-column surface-temperature supersaturation.
  - add conservative lifting condensation from fronts, cyclones and orographic ascent: diagnose LCL from local RH, lift a fractional parcel, cool it at dry/moist adiabatic lapse rates and transfer only available vapor into physical cloud condensate
  - use existing frontVerticalVelocity/frontStrength, systemVerticalVelocity/cycloneStrength and orographicVerticalVelocity/orographicRoughness; no latitude cloud mask or decorative storm-track band is introduced
  - anticyclonic subsidence strongly suppresses the ascending cloud fraction, retaining physically clearer subtropical/high-pressure regions while allowing humid frontal storm tracks to cloud over
  - damp overlap with the existing deep-convective plume microphysics so synoptic lift and thunderstorms do not condense the same sub-grid parcel twice
  - publish resolvedLiftCloudPotential/area/depth/condensation-rate diagnostics and feed only that physical diagnosis into the inertial cloud visual response, preventing coarse-cell RH below 0.78 from instantly erasing a real lifting cloud
  - preserve local/global H2O conservation and existing latent heating: every kilogram of new cloud water is removed from vaporColumn, and condApplyLatentHeat remains the single latent-heat path
  - keep the new work off render FPS: the coupling is a deterministic O(N) pass inside the existing fixed Weather Core condensation step and skips dry/non-lifting cells before expensive LCL/saturation calculations
  - calibration reference follows observed Earth climatology rather than a hard-coded map: cloud-rich tropical convergence and mid-latitude storm tracks, with relatively clearer descending subtropics
Regression: resolved-lift-clouds.test.js checks sub-saturated frontal cloud formation, exact H2O conservation, no-lift/dry-air rejection, anticyclonic suppression, visual persistence coupling and build order.
Snapshot: 0.5.129 remains the rollback point before resolved lifting condensation.

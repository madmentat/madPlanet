VERSION 0.5.61
Base: 0.5.60
Changes: Repository audit and regression hardening after the 0.5.60 weather stabilization pass. GitHub Actions now rebuilds index.html and runs the complete regression suite on develop/main pushes and pull requests. tests/run-all.sh keeps build/syntax gates fail-fast but runs all independent regression tests before reporting failures, so one stale assertion no longer hides the rest. Several old tests were updated to verify semantic behavior instead of obsolete exact file adjacency, milestone version strings, comments containing forbidden API names, or validation code that has since moved into madlib.ps1. Cryosphere compaction scenarios are isolated from meltwater left by the preceding test, and the 0.5.60 sublimation regression now explicitly requires cryosphere coverage and RH refreshes after mass transfer. One real cloud-behavior defect found by the audit is fixed in js/cloud-visual-response.js: neighbour blending is reduced from 0.22 to 0.10 per five-minute Weather Core tick. At 0.22, surrounding dry/subsident cells could overpower a persistently humid/lifting cell faster than its intentionally slow local growth response, eventually turning a genuine cloud-growth magnet into a disperser. The lower blend still softens cubed-sphere boundaries without reversing sustained local forcing.
Roadmap note: continue the 0.5.60 stabilization goal before adding new visual milestones. The next physics audit target remains the old multiplicative global H2O normalization in precipitation.js/h2o-advection.js. It currently enforces exact atmosphere + landed-store closure every fixed tick; before replacing it, add a long-run Earth-like conservation/stability test so any softer correction can be judged against warm-latitude RH, cloud persistence and polar H2O storage rather than appearance alone.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

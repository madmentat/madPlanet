VERSION 0.5.114
Base: 0.5.113
Changes: Decouple the visible frame loop from fixed Weather Core cadence so orbit, zoom and animated effects no longer hitch once per weather tick.
  - Weather Core desktop grid reduced from 48x48 to 36x36 cells per cubemap face; the physical grid remains synoptic while shader detail stays full-resolution
  - replace setInterval(weatherCoreTick, 1000) with a non-overlapping cooperative scheduler using requestIdleCallback when available; missed real-time ticks are never replayed
  - weather physics defers while the user is dragging, pinching or wheeling, while paused/hidden, and while the full shader is still compiling
  - cloud, fog and cryosphere GPU target publication is removed from the visible fixed-tick burst by rebinding uploads to a coalescing idle queue; one visual target is published per idle turn
  - first frame, seed changes and texture-size changes remain synchronous so a regenerated planet never displays stale weather from the previous world
  - expensive cryosphere publication is throttled to about 2.4 s on mobile and 1.8 s on desktop, while its scalar edge field continues to interpolate continuously between targets
  - Weather Core scheduler records last/EMA tick cost in window.__madPlanetWeatherScheduler for profiling without forcing synchronous GPU timing
Regression intent: fixed-step determinism is unchanged; render FPS still never drives weather integration; visual target blending remains continuous and no catch-up work occurs after hidden/interactive periods.
Snapshot: 0.5.113 remains the rollback point before frame-pacing decoupling.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

VERSION 0.5.116
Base: 0.5.115
Changes: Extend the right-side tool rubric with a second eight-slot column and add a lightweight schematic Orbit mode.
  - the existing eight parameter buttons remain in their original right-hand column; a second eight-slot column appears immediately to the left, aligned above the runtime/performance settings gear
  - the new Orbit button starts at the top of the new column, leaving seven empty positions available for later tools
  - all sixteen toolbar positions are draggable; dropping onto an occupied cell swaps the two buttons, while dropping onto an empty cell moves the button there
  - custom toolbar layout persists in localStorage for this browser/device and never enters the planet seed/hash
  - empty desktop cells stay visually quiet and become dashed drop targets only while rearranging; narrow-phone layout remains a horizontally scrollable tool strip rather than consuming screen width with two vertical columns
  - Orbit mode uses a small 2D overlay canvas rather than the main WebGL pass, so it adds negligible rendering cost
  - the schematic shows the orbital plane, star, current planet position, star direction, orbital quarter marks, orbital normal, physical spin axis and axial-tilt angle
  - season label, solar declination, orbital distance and year length are derived from the existing season/star/planet physics rather than duplicated UI-only formulas
  - orbit rendering is inserted before runtime-settings wraps drawFrame, so the orbit marker receives the same continuously scaled simulation clock as the planet while Pause still freezes it
Regression: toolbar remains responsive and panel positioning still measures the full rubric rectangle; existing group button click handlers survive reparenting into draggable slots.
Snapshot: 0.5.115 remains the rollback point before the second toolbar column and Orbit schematic.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

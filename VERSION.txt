VERSION 0.5.54
Base: 0.5.53
Changes: Weather Core cloud visuals v1 + morphology hotfix - the physical cubed-sphere weather grid still owns where visible low, middle and high clouds are allowed: RGBA8 uWeatherCloudTex carries cloudLowMass/cloudMidMass/cloudHighMass plus deepConvectiveState and uploads only after Weather Core creation/fixed weather ticks, never from requestAnimationFrame. The first 0.5.54 visual bridge exposed the coarse 48x48x6 Weather Core texels as repeated round/square cloud tokens by thresholding physical q directly into optical density. The hotfix keeps the new physical geography but restores the mature 0.5.53 cloud bodies: legacyLowDeck/legacyMidDeck/legacyHighDeck and matching cover functions provide connected cumulus banks, middle-deck texture and high wisps, while physical q is only a continuous multiplicative envelope. q==0 remains strictly clear, so procedural morphology cannot create clouds outside physical condensate; deepConvectiveState still strengthens towers/anvils. Procedural synoptic(), weather() and lowCloudClimate() remain disabled as geography sources. The unfinished 0.5.55 radiative-feedback experiment was removed before this repair and is not part of the hotfix.
Roadmap note: cloud shadows/radiative feedback stays next, but only after this hybrid physical-geography + legacy-morphology visual layer is validated in-browser.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

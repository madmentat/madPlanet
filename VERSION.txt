VERSION 0.5.54
Base: 0.5.53
Changes: Weather Core cloud visuals v3 - visible clouds are never clipped by a Weather Core mask. The mature continuous 0.5.53 morphology remains authoritative for low/mid/high cloud bodies. Weather Core exports only persistent signed influence fields cloudVisualLow/cloudVisualMid/cloudVisualHigh: positive values are growth magnets, negative values dispersers, zero is neutral. The response is driven by humidity/saturation, condensation, orographic/frontal/cyclone lift, deep convection, dryness, cloud evaporation and subsidence. Formation and dissipation have separate finite response times (about 95 and 70 simulated minutes before moisture/cloud-mass modifiers); existing condensate increases resistance to dispersal; one cheap cross-face neighbour diffusion pass broadens forcing zones beyond raw 48x48 cubed-sphere cells. The GLSL influence only shifts formation thresholds/coverage parameters inside the old continuous cumulus/mid/wisp morphology and is never multiplied as a finished-density visibility gate. This hotfix additionally removes temporal stepping: the GPU bridge is now double-buffered with previous/current RGBA8 influence cubemaps. Fixed Weather Core ticks still publish targets only at weather cadence, but every render frame interpolates between them with uWeatherCloudBlend. Before a new target is accepted, CPU buffers collapse to the exact currently visible interpolated state, preserving continuity under timer jitter or short stalls. A seed/world replacement resets both buffers to the same new target instead of cross-fading unrelated planets. No texture upload occurs on render FPS; the extra per-frame cost is only a second cubemap sample plus mix/uniform blend. Procedural synoptic/weather/climate geography stays retired. The unfinished 0.5.55 radiative-feedback experiment remains removed until cloud visual behaviour is validated in-browser.
Roadmap note: physical cloud shadows/radiative feedback stays next after validation of the inertial magnet/disperser model with temporal interpolation.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

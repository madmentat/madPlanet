VERSION 0.5.54
Base: 0.5.53
Changes: Weather Core cloud visuals v2 - visual clouds are no longer clipped by any Weather Core mask. The mature continuous 0.5.53 cloud morphology remains authoritative for the actual low/mid/high cloud bodies. Weather Core now exports only a slowly varying signed influence field: positive values act as cloud-growth magnets, negative values as dispersers, zero is neutral. The persistent cloudVisualLow/cloudVisualMid/cloudVisualHigh response is driven by humidity/saturation, condensation, orographic/frontal/cyclone lift, deep convection, dryness, cloud evaporation and subsidence. Formation and dissipation have separate finite response times (about 95 and 70 simulated minutes before moisture/cloud-mass modifiers), so cloud banks cannot appear or vanish in a single weather tick. Existing condensate increases resistance to dispersal, giving a strong but finite disperser capacity instead of deletion by boundary. The response field receives one cheap cross-face neighbour diffusion pass per Weather Core tick so forcing zones are broader and softer than the 48x48 cubed-sphere cells. The RGBA8 cubemap now carries signed inertial influence in RGB (-1..+1 encoded around neutral 0.5) plus deepConvectiveState in A, not cloud mass/opacity. In GLSL the influence only shifts the old 0.5.53 formation thresholds and local coverage parameters inside cumulus/mid/wisp noise fields; it is never multiplied as a finished-density gate and can never draw a square Weather Core cell edge into a cloud. Procedural synoptic/weather/climate geography stays retired. The unfinished 0.5.55 radiative-feedback experiment remains removed until this visual behaviour is validated in-browser.
Roadmap note: physical cloud shadows/radiative feedback stays next after validation of this inertial magnet/disperser model.

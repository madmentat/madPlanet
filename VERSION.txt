VERSION 0.5.52
Base: 0.5.51
Changes: physical lightning v1 - lightning centres now come only from Weather Core deep moist convection. Each cell diagnoses electrical potential from persistent deepConvectiveState, CAPE-driven sub-grid updraft speed, condensate, precipitation and the vertical depth of the 0..-35 C mixed-phase cloud zone used as a charge-separation proxy. Dry/stable/shallow clouds cannot create a lightning centre. Up to five spatially separated strongest physical cells are exported to the shader; flash cadence is derived from plume/updraft/precipitation and is capped at 4.5 flashes/s per cell, so truly extreme climates can still produce machine-gun lightning without procedural storm placement. The five retired uCycA/uCycB slots are temporarily reused as a compact render transport until the 0.5.53 Weather Core cloud-visual rewrite: A.xyz carries the body-fixed storm centre while A.w stays exactly zero, so legacy synoptic()/vortexWarp() remain disabled; B carries storm radius, physical cadence, electrical intensity and deterministic phase. Shader randomness is now only strike jitter inside a physical storm, never global storm placement. storm/stormRate/stormGlow remain visual/cadence multipliers and cannot create a storm when Weather Core has no eligible deep-convective cell.
Design note: add explicit Realism and Sandbox simulation modes. Realism keeps the causal/derived attractor chain; Sandbox must allow direct parameter overrides without automatic relaxation/recalculation, including intentionally absurd lightning. 0.5.52 keeps Realism semantics for physical storm existence and is structured so a later Sandbox override can sit on top without restoring procedural weather to Realism.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

VERSION 0.5.51
Base: 0.5.50 (including ui/random polish)
Changes: local Weather Core deep moist convection v1 - each cell now diagnoses CAPE/CIN-like parcel energy from the resolved surface/air thermal contrast, humidity, LCL, pressure scale height and gravity, while orographic/frontal/cyclone ascent can erode inhibition and anticyclonic subsidence rebuilds it. A persistent deepConvectiveState grows and decays on storm timescales and drives a bounded sub-grid plume updraft from sqrt(2*CAPE), plume area/moisture flux and a physical upper-cloud target; plume speed is explicitly not treated as resolved whole-cell vertical motion. A conservative coupling accelerates condensation inside lifted moist plumes and autoconversion of mature condensate into convective rain/snow using the existing vapor/cloud/surface reservoirs and latent-heat owner, so no H2O source is introduced. The existing vertical cloud-column diagnosis consumes the deep plume target to raise cloud tops and repartition the same cloudWaterState into low/mid/high mass without changing bulk condensate. Deep convection remains CPU Weather Core physics only; lightning coupling is reserved for 0.5.52 and GLSL cloud visual coupling for 0.5.53.

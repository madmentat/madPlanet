VERSION 0.5.55
Base: 0.5.54 (cloud temporal fix)
Changes: Physical cloud shadows + radiative feedback. The stabilized 0.5.54 cloud morphology/inertia/temporal interpolation is preserved unchanged. Visible surface shadows continue to use lowCover/midCover from the same double-buffered, temporally interpolated physical cloud influence that drives visible clouds, so shadows grow, decay and advect with the cloud body and disappear when the corresponding layer is OFF; raw Weather Core condensate is never used as a geometric shadow mask. New js/cloud-radiative-feedback.js converts the 0.5.40 local energy budget to a clear-sky/ice/aerosol baseline by removing the legacy 0.230*cloudCov global cloud-albedo contribution and retiring the old local cloudWater albedo perturbation. Once per fixed Weather Core tick, real cloudLowMass/cloudMidMass/cloudHighMass produce layer-specific shortwave reflection and longwave trapping. Low thick clouds have the strongest SW reflection; high cold clouds reflect less SW but can strongly reduce OLR. Layer cloud-top temperatures are estimated from the resolved cloud base/top geometry and environment lapse rate, while gaseous optical depth attenuates cloud LW forcing when the IR window is already closed. The resulting cloudShortwaveForcing/cloudLongwaveForcing/cloudNetForcing modify local surface temperature through the existing heat capacity and update localAlbedo/absorbedSolar/outgoingLongwave/netRadiation diagnostics without changing H2O, pressure or wind. Diagnostics now report area-weighted cloud SW/LW/net forcing and radiative cloud cover. No cloud-radiative work runs on render FPS.
Roadmap note: next stage returns to the weather roadmap after validating that cloud feedback remains numerically stable across temperate, stormy and high-pressure worlds.

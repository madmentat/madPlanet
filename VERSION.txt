VERSION 0.5.181
Changes: reliably visible, artistically routed surface rivers.
  - Catchment-based D8 topology routes only downhill, including lake mouths.
  - Small cached offsets break rigid cell-grid river paths; inexpensive shader bends keep common junctions.
  - Deferred river atlas generation resumes after asynchronous terrain shader compilation.
  - Orbital display uses a limited screen-space line-width floor so real rivers are not subpixel-invisible.
  - Single analytic raster segment per drainage edge; no expensive multi-segment CPU spline passes.
Validation: Node regression suite, deferred-atlas retry regression, synthetic one-mouth/downhill checks.
Regression seeds: 8127344, 55807208, 5569959.
Compatibility: routed rivers need WebGL2 and at least nine fragment texture units; fallback renderer has no rivers.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

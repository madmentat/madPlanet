VERSION 0.5.60
Base: 0.5.59
Changes: Physical snow / land surface ice / sea ice plus stabilization hotfix after visual validation. New js/cryosphere.js keeps snow, land ice and sea ice as persistent Weather Core state driven by real snowfall, land-skin temperature, SST, latent heat and model time; shaders/surface.glsl no longer generates polar caps from decorative latitude/temperature masks. The stabilization pass addresses the observed ~17 C regression where initially healthy clouds gradually disappeared, activity concentrated near the poles and grid-shaped bright patches appeared. js/weather-target-smoothing.js removes the old per-cell hash from equilibrium Weather Core targets so a bootstrap perturbation no longer becomes permanent grid-scale temperature/pressure forcing. js/h2o-column-thermodynamics.js replaces the isothermal p_sat/g saturation slab with a Clausius-Clapeyron vertical-profile approximation and makes the slow one-box H2O equilibrium use the same definition, so warm Earth-like cells can have ordinary meteorological RH instead of artificial RH~0.2. js/cryosphere-sublimation.js adds a conservative snow/land-ice -> vapor return path for dry cold air, preventing landed polar H2O from being a strictly one-way sink. js/fog-spatial-fix.js diffuses diagnostic fog state over neighbouring Weather Core cells before GPU publication; shaders/fog.glsl removes the hard optical<0.002 contour and uses only subtractive edge erosion plus a smooth fade, specifically targeting the magnified cubemap rectangle/cross artifact. js/weather-audit-diagnostics.js exposes warm-band RH, vapor/saturation columns, cloud/fog state, polar landed cryosphere and resolved wind so the cold-trap can be measured over hundreds of ticks. Cloud morphology itself remains the mature 0.5.53 procedural body controlled by the inertial/temporally interpolated Weather Core influence; it was not rolled back.
Roadmap note: pause new roadmap milestones after 0.5.60 until an Earth-like ~17 C validation world survives hundreds of Weather Core ticks without monotonic warm-latitude drying or runaway polar H2O storage. If those trends remain, the next stabilization step is removal/replacement of the old multiplicative global H2O normalization rather than another cloud-render rewrite.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

VERSION 0.5.118
Base: 0.5.117
Changes: Add an optional schematic orbit line to the main scene, controlled from inside the draggable Orbit instrument window.
  - Orbit mini-map gains a compact "Орбита в основной сцене" toggle rather than consuming another toolbar cell
  - when enabled, a lightweight full-screen 2D instrument overlay projects a warm orbital line around the system star while the normal photorealistic WebGL planet render stays untouched
  - the schematic ellipse is anchored to the same star direction used by the sky pass, oriented from the physical ecliptic plane, and mathematically constrained to pass through the current planet at screen centre
  - the line is intentionally not astronomical scale: it behaves like a diagram/field-line aid, with a faint glow, solid near side, dashed far side, star marker and a small current-planet marker
  - the scene orbit is visible only while Orbit mode itself is open; closing Orbit hides it immediately while remembering the toggle preference for the next opening
  - the toggle preference is stored in localStorage for this browser/device and never enters planet state, hash or seed
  - Orbit window height expands only enough for the new switch; the existing drag handle, close button and saved window position continue to work
Regression: bash and PowerShell builders load orbit-scene-path.js between Orbit drag behavior and the other instrument overlays; tests guard star anchoring, physical ecliptic orientation, planet-through-ellipse geometry and local display-only persistence.
Snapshot: 0.5.117 remains the rollback point before the main-scene orbit-line option.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

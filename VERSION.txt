VERSION 0.5.72
Base: 0.5.71
Changes: Atmospheric visibility diagnostics + warm-world cryosphere bootstrap correction. The Weather panel now has a single explicit «Видимость атмосферы · только рендер» block with real on/off toggles for lower, middle and upper clouds, physical near-surface fog, lightning, atmospheric scattering/halo and aurora, plus Hide all / Show all actions. These flags only affect rendering: Weather Core, gas inventory, condensation, lightning physics and magnetic activity continue evolving while hidden. Fog is no longer coupled to the low-cloud switch, and direct lightning can remain visible while the lower cloud deck is hidden, making ambiguous white/milky features diagnosable instead of guessed.
Temperature fix: climateModel().T is documented and displayed as the planet-wide mean surface temperature, but the old smooth Weather Core bootstrap treated it as an equatorial temperature and then subtracted up to 38 K toward the poles. Because the spherical mean of |sin(latitude)|^2.4 is 1/3.4, the physical grid silently started about 11.18 K colder than the headline thermometer. A displayed +23 °C world therefore bootstrapped near +12 °C on average, creating an excessively broad transient freezing zone which later melted only slowly. The latitude profile is now mean-neutral: the equator is warmer and the poles colder than the headline value, but the area-weighted mean remains the displayed global mean.
Diagnostics note: after deployment, use Hide all in the Weather visibility block to see the bare surface/cryosphere. Then enable fog, lower clouds and atmospheric scattering one at a time. This should make it immediately clear whether a white feature is authoritative snow/ice or an atmospheric layer. Old named links remain compatible; new visibility flags default ON unless an updated link explicitly stores them.
Retained: 0.5.71 shore-first inland/ocean freeze morphology, 0.5.70 crisp polar ice reconstruction, 0.5.69 cold-stress biomes and latitude thermometers, 0.5.68 broken auroral curtains and 0.5.67 hydrology-shaped vegetation remain unchanged.
Validation note: reload a warm world around +20…+25 °C so Weather Core is created from the corrected mean-neutral target. A large quarter-planet transient cap should no longer be created merely by the bootstrap latitude bias. Some high-latitude snow/ice may remain physically valid depending on axial tilt, season, water inventory and local energy balance. If a mature +23 °C world still retains an implausibly huge cap with all atmospheric rendering hidden, the next physics target is explicit meridional sensible/ocean heat transport rather than another visual ice mask.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

VERSION 0.5.83
Base: 0.5.82
Changes: Removed the square/stair-step polar ice plateau introduced by the 0.5.81 hard-edge fix, retuned mobile frame pacing for visibly smoother motion, corrected landscape-tablet Weather Core classification, and added a compact live HUD under the world number with FPS, mean planet temperature, stellar class and orbital distance.
Cryosphere contour: 0.5.81 solved the translucent polar halo by forcing the cryosphere cubemap to NEAREST filtering. That exposed every reconstructed texel as an axis-aligned square at close range. 0.5.83 restores LINEAR sampling but no longer treats the interpolated value as kilometres of optical transparency. Transitional physical coverage is published as a continuous edge field and the surface shader converts it to a material boundary with approximately one screen pixel of anti-aliasing. Dense ice remains solid and sparse sea ice still obeys the 15% display cutoff.
Tablet tick fix: Weather Core used only a <=700 px media query to choose its 32x32x6 mobile grid. A landscape Android tablet could therefore be treated as desktop physics at 48x48x6 even while the renderer correctly treated it as mobile. Coarse-pointer/mobile-UA/compact devices now use the intended 32x32x6 grid, cutting the fixed-tick cell count from 13824 to 6144 on the affected tablets.
Frame pacing: mobile adaptive quality now targets roughly 20.5 ms per frame (~49 fps) instead of about 31 ms (~32 fps). The renderer may reduce internal scale to 0.70 on ordinary mobile hardware or 0.62 on low-memory devices when necessary. Dynamic-resolution changes are suspended during active drag/pinch and quality recovery is deliberately slow, avoiding repeated framebuffer reallocations that themselves look like hitches.
Cryosphere cost: the new smooth contour lets mobile cryosphere display reconstruction use 4x rather than 5x Weather Core resolution while desktop retains 5x, reducing once-per-weather-tick CPU work without returning visible block edges.
Telemetry: the top-left world mark now gains a throttled live readout for FPS, mean climate temperature in Celsius, current stellar spectral class and orbital distance in AU. DOM text is refreshed only a few times per second rather than every rendered frame.
Regression: smooth-motion-ui.test.js guards tablet physics classification, mobile frame target and scale headroom, no quality resize during active pointer input, LINEAR cryosphere sampling plus screen-space edge AA, module build order, and all four requested telemetry values. The existing hard-edge regressions remain active to prevent the old grey Arctic lens from returning.
Validation: confirm visible stamp v0.5.83. On the same close polar views, ice boundaries should no longer build from obvious right-angle blocks. Drag, pinch, inertial rotation and automatic planet rotation should feel materially smoother on the tablet; the new FPS number should make remaining device-specific stalls measurable. Genuine weather fields remain fixed-step physically, while their established GPU bridges continue interpolating visual cloud/fog state between weather ticks.
Snapshots: snapshot/0.5.78 through snapshot/0.5.82 remain retained. Create snapshot/0.5.83 after release CI passes.
Retained: 0.5.82 binary deep-cold closure (no grey Arctic lens); 0.5.81 opaque cryosphere phase logic and +15 C cap trim; 0.5.80 gradual/irreversible volatile loss; 0.5.79 uncapped hot equilibrium; 0.5.78 phase/biology gating.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

VERSION 0.5.167
Base: 0.5.166 final random-world thermal acceptance.
Changes: prevent Random from remaining trapped on the snowball climate branch.
  - climate-consistency continuously writes the current Weather Core surface temperature back into state.temp.
  - climateModel() uses state.temp as the initial condition of its nonlinear ice/albedo iteration, so after one -70..-90 C probe later orbital probes could remain on the frozen attractor even when moved substantially inward.
  - Every Random orbital probe now invalidates the old Weather Core, warm-starts state.temp from the +14..+24 C target, settles H2O, and only then creates a fresh Weather Core.
  - The HZ search bracket is now adaptive: if the inner probe is still cold it expands inward; if the outer probe is still hot it expands outward.
  - The final solver result is exposed in window.__madPlanetHabitableRandomThermalFix.last for diagnosis.
  - Regression test starts from an artificial -70 C snowball branch and requires Random to escape it and converge into the temperate target band.
  - Manual worlds and ordinary climate evolution are unchanged; warm-starting is restricted to Random generation.
Regression: a frozen state.temp must not trap Random on the cold attractor.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

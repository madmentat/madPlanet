VERSION 0.5.67
Base: 0.5.66
Changes: Biome de-grid pass after deployed 0.5.66 exposed the low-resolution Weather Core cubed-sphere directly in vegetation colour. The physical soil-wetness/temperature texture remains coarse and cheap, but it is now only a broad ecological envelope instead of a majority blend into the biome moisture scalar. Existing fine vegetation noise fields are moved earlier and reused as sub-cell ecological structure, so green/dry patches become smaller, more numerous and irregular without adding extra FBM evaluations. Existing river/lake geometry is likewise computed once before biome colouring and reused: floodplains, lake margins and low wet coastal terrain boost ecological moisture, resist drought and receive riparian vegetation, while actual water rendering later reuses the same geometry. This makes vegetation preferentially follow water corridors instead of appearing as arbitrary square blocks. We deliberately do not raise Weather Core from 48x48 to 96x96: that would roughly quadruple physical-cell work, while simple texture upscaling would mostly preserve the same large quadrilateral contours. The de-grid strategy therefore keeps simulation cost essentially unchanged and spends the already-existing shader detail more intelligently. 0.5.66 cloud visibility controls and final cryosphere-over-biome ordering remain intact.
Validation note: hide all cloud decks and inspect broad wet/dry transitions at several zoom levels. No large square/diamond/symmetric cubed-sphere cells should be readable in green cover. Vegetation should break into finer natural patches and preferentially thicken along river corridors, around lakes and in wetter lowlands; hot dry interiors should still brown out. Zooming must not change ecological floodplain width because the greening width is world-space rather than pixel-space.
Roadmap note: after visual validation, consider a separate rare optional 'biosphere anomaly' feature for genuinely unusual large-scale geometric/ecological patterns so an occasional deliberate-looking formation can exist without contaminating ordinary natural biomes. Longer-term biome work still needs persistent vegetation recovery/seasonality/fire state; atmospheric H2O-normalization stability remains the main weather architecture task.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

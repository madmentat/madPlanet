VERSION 0.5.76
Base: 0.5.75
Changes: Tectonic Voronoi cell-boundary artifact repair. The thin black/white/dotted arcs circled in the 0.5.75 close-up were distinct from the old periodic fold ribbons. The tectonic pair model had already stopped selecting one nearest pair, but its pair reach/fade weights still subtracted a hard nearest-plate dmin. min() is continuous in value but has a derivative kink where the nearest plate identity changes; shadeSurface obtains normals by finite-difference calls to terrain(), so that hidden derivative kink was exposed as a one-pixel arc following the weighted Voronoi cell boundary even with the Plates overlay disabled.
Fix: terrain relief weights now use a cheap C1 polynomial smooth-min reference dRef across all active plate distances. The hard nearest identity remains only for optional diagnostic plate tint and no longer enters relief, normals, volcanic distance weighting or climate. Pair seam geometry itself is unchanged because the common reference cancels from dj-di; REACH pruning and existing performance structure remain intact.
Regression: tests/tectonic-cell-seams.test.js requires both pair sides to use dRef and forbids hard dmin from re-entering the tectonic pair loop. The 0.5.75 regression also continues to forbid the old periodic cos(distance_to_seam) fold generator.
Technical check: native GLSL smoothstep with reversed edges would be undefined by the GLSL specification, but madPlanet's ss() is a custom Hermite helper that explicitly supports reversed endpoints, so the existing reversed REACH fade is not the source of these lines.
Validation note: verify the visible stamp says v0.5.76, keep Plates visually OFF, and revisit a close tectonic land view like seed 46204625. The isolated razor-thin black/white arcs should be absent; real ridges, valleys, rivers and broad volcanic terrain may remain. If a remaining line tracks only active volcanism, test Vulkanism=0 separately because that is a different display path from the terrain-normal seam fixed here.
Retained: 0.5.75 solid/dense polar ice display and non-periodic fold morphology, 0.5.74 cryosphere cubemap seam repair, 0.5.73 slower land-glacier formation, 0.5.72 atmospheric diagnostic toggles, 0.5.71 shore-first freezing, 0.5.69 cold-stress biomes and temperature diagnostics.

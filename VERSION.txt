VERSION 0.5.161
Base: 0.5.160 terrain-driven river drainage.
Changes: review fixes for the bake/drainage lifecycle.
  - state.sea is a per-frame derived value, so the bake signature quantises it to 0.01 and any changed signature must hold for 1.5 s before a rebake; previously every water-budget transient triggered a GPU bake and a full Priority-Flood rebuild per tick.
  - The terrain bake program links asynchronously (KHR_parallel_shader_compile, or a 2.5 s grace period) and is started right after GL init; an incomplete bake framebuffer disables the bake so the synoptic fallback owns the bridge.
  - Fine land inside a coarse "ocean" Weather Core cell inherits its land neighbours' runoff instead of zero, so tectonic islands and coastal strips can carry rivers.
  - A tributary's last edge keeps its own width at the junction; chords publish inside the same paced upload as the raster corridor; the worker publishes rivers only through its own message; drainage scratch arrays are reused.
Regression: guards require the quantised sea signature, the settle delay, asynchronous link status, the framebuffer failure flip, the coarse-ocean wetness fallback, the junction width rule and the single worker publication.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.

VERSION 0.5.90
Base: 0.5.89
Changes: The normal-path fix described in 0.5.89 was missing from surface.glsl. The global bump gain (0.03 + 0.095*uTect) was still applied to every land pixel, so raising Tectonics continued to amplify ordinary base-terrain FBM gradients into residual smooth curved stripes far from plate boundaries.
Actual implementation: localTectSupport = max(ss(0.01,0.08,mount), 1.0 - ss(0.05,0.20,seamNearCenter)). The Tectonics contribution to finite-difference normal strength is now gated by real tectonic height or proximity to a genuine plate margin. Deep plate interiors keep only the neutral 0.03 base gain.
Validation: seed 90636862 (or any previously problematic area), sweep Tectonics 0% -> 100% with Plates off. Distant smooth arcs must no longer strengthen merely because the slider is raised. Real mountain systems and plate-margin structure must still respond.
Snapshots: snapshot/0.5.89-pre-normal-fix is the rollback point before this change.
Retained: all prior pairCompetitive, broad seamGate and diagnostic fixes from 0.5.86-0.5.89.
Release rule: every new archive increments patch version by 0.0.1 and is named madPlanet-X.Y.Z.zip.
